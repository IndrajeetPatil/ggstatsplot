# Additional vignettes

Due to size constraints, most vignettes are only available on the
website for this package. The articles index lists all of them,
including articles for each primary function (and its `grouped_`
variant), frequently asked questions, pairwise comparisons,
interpretation of Bayes factors, and the design principles guiding the
package:

<https://www.indrapatil.com/ggstatsplot/articles/>

## Publication

A journal article describing the philosophy and principles behind this
package: <https://joss.theoj.org/papers/10.21105/joss.03167>

## Presentation

Another quick way to get an overview of this package is to go through
the following slides: <https://www.indrapatil.com/intro-to-ggstatsplot/>

## Statistical backend of `{ggstatsplot}`

The [statsExpressions](https://www.indrapatil.com/statsExpressions/)
package forms the statistical backend that processes data and creates
data frames and expressions containing results from statistical tests.

For more exhaustive documentation for this package, including a summary
of all supported statistical tests and effect sizes, see:
<https://www.indrapatil.com/statsExpressions/>
